# Sentiment Analysis Using Python

## About the Project
This project focuses on analyzing text data and classifying sentiment using Natural Language Processing (NLP) and machine learning techniques. It was completed as part of my **Data Analytics Internship at Oasis Infobyte**.

## Objectives
- Analyze and preprocess text data.
- Convert text into numerical features using TF-IDF.
- Train and compare machine learning models.
- Evaluate model performance using classification metrics.
- Visualize sentiment distributions and misclassified examples.

## Dataset
- **Source:** [Twitter Entity Sentiment Analysis - Kaggle](https://www.kaggle.com/datasets/jp797498e/twitter-entity-sentiment-analysis)
- **Main columns:** `id`, `entity`, `sentiment`, `tweet`

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- TF-IDF Vectorization
- WordCloud

## Project Workflow
1. Load and inspect the dataset.
2. Clean and preprocess tweet text.
3. Explore sentiment distributions.
4. Extract text features using TF-IDF.
5. Train Multinomial Naive Bayes and Logistic Regression models.
6. Evaluate models using accuracy, precision, recall, F1-score, and confusion matrices.
7. Visualize results and examine incorrect predictions.

## Key Learnings
- Understanding text preprocessing and NLP fundamentals.
- Applying TF-IDF for feature extraction.
- Comparing classification algorithms.
- Evaluating machine learning models using multiple metrics.

## Conclusion
This project provided practical experience in text classification, sentiment analysis, and machine learning evaluation using Python.
